🔑 설정

1. PC·폰이 같은 방을 보게 하기 (GitHub 공용 파일)

카톡방을 PC와 폰이 똑같이 보려면 공용 칠판이 하나 필요합니다. 이 앱은 깃허브 저장소 안의 office-messages.json 파일을 칠판으로 씁니다. 10초마다 칠판을 읽고, 새 메시지를 칠판에 적습니다. 칠판에 글을 쓰려면 PAT(개인 액세스 토큰 = 내 깃허브에 글을 쓸 수 있게 해주는 비밀번호 같은 열쇠)가 필요합니다. PAT가 없으면 이 브라우저(기기)에만 대화가 저장됩니다.

발급 방법: github.com/settings/tokens → Generate new token (classic)(새 토큰 만들기) → 이름 아무거나 → repo 칸 체크(저장소 읽기·쓰기 허용) → 맨 아래 Generate token(토큰 만들기) → 나온 ghp_...를 복사해 위에 붙여넣기.

2. AI 직원 연결 (무료 API 키)

API 키는 AI 회사가 발급하는 ‘이용증’입니다. 키를 넣으면 각 포지션이 진짜 AI로 릴레이 회의를 합니다. 키가 없거나 한도를 다 쓰면 데모 모드(정해진 예시 대화로 회의 흐름만 보여주는 연습 모드)로 돌아갑니다. 키는 이 브라우저(localStorage)에만 저장되고, 답변을 만들 때 해당 AI 회사로만 전송됩니다.

발급: aistudio.google.com/app/apikey → Create API key(API 키 만들기) → 복사.

발급: openrouter.ai/keys → Create Key(키 만들기). 모델 이름 끝에 :free가 붙은 것을 쓰면 무료입니다.

※ 무료 모델 이름은 자주 바뀝니다. 오류가 나면 무료 모델 목록에서 지금 되는 이름으로 바꿔 주세요.

3. 포지션별로 어느 AI가 답할지

‘자동’은 키가 있는 쪽을 씁니다. 포지션 이름(GPT·클로드·제미나이)은 역할 별명이고, 실제 모델은 여기서 정합니다.
