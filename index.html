⚙️ 연결 설정

키를 넣은 직원은 실제 AI로, GitHub PAT를 넣으면 피클 팀이 실제로 움직입니다. 모든 값은 이 브라우저(localStorage)에만 저장되고, 답변을 만들 때 해당 제공사로만 전송됩니다. 따로 만든 서버는 없습니다.

무료 등급은 분당·일일 한도가 있습니다. 한도를 넘으면 잠시 뒤 다시 시도하거나 데모로 확인하세요. 공용 PC에서는 키를 저장하지 마세요. GitHub PAT는 이 저장소의 Contents 쓰기만 주는 토큰을 권장합니다.

잔여 한도

제공사 대시보드에 보이는 남은 양을 그대로 옮겨 적으면 됩니다. 여기 적은 값은 이 브라우저에만 저장돼요.

❓ 사용 안내

처음 쓰신다면 이 다섯 가지만 기억하면 됩니다.

1. 그냥 말하기
“몽골 중고차 수출 아이디어 검증해줘”처럼 평소 말투로 적으면 담당자에게 갑니다(공용창이 연결돼 있으면 팀장 @방카르1, 아니면 @GPT).

2. @로 지목하기
@전체면 연결된 직원이 차례로, @방카르2처럼 한 명만 찍으면 그 직원만 답합니다. 아래 칩을 눌러도 입력창에 들어가요.

3. 두 팀의 차이
피클 팀(방카르 1·2·3)은 GitHub 공용 파일에 지시를 남기고, 피클이 일을 마치면 보고가 파일에 쌓입니다. 외부 AI(GPT·클로드·제미나이)는 이 화면에서 바로 답합니다.

4. 진짜로 쓰기
⚙️에서 API 키(외부 AI) 또는 GitHub PAT(피클 팀)를 넣으세요. 답변 오른쪽 위 라벨로 실제/데모를 구분할 수 있습니다.

5. 퀵 버튼
회의 정리(지금까지 요약) · 할 일 뽑기(실행 목록) · 초안 쓰기(홍보 문구)를 한 번에 시킬 수 있습니다.
