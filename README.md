# AI 소통창 (ai-meeting-room)

카카오톡 단톡방처럼 생긴 **AI 직원 6명 소통창**입니다. 대표(사용자)가 한마디 하면 포지션별 AI들이
직전 대화를 모두 읽고 서로를 부르며 **릴레이 회의**를 합니다. 앱: <https://bjyoutube.github.io/ai-meeting-room/>

- 단일 `index.html`. 빌드·서버 없음. PC와 스마트폰에서 같은 화면.
- 공용 칠판: 같은 저장소의 `office-messages.json` — PAT가 있으면 10초마다 읽고 새 메시지를 커밋·푸시해
  PC·폰이 같은 방을 봅니다. PAT가 없으면 그 브라우저(localStorage)에만 저장됩니다.
- AI 키(Google AI Studio Gemini / OpenRouter)가 있으면 실제 AI로, 없으면 **데모 모드**(정해진 예시 대화)로
  회의 흐름을 그대로 볼 수 있습니다. 키는 브라우저에만 저장되고 저장소에는 올라가지 않습니다.

## 포지션과 회의 순서

| 번호 | 포지션 | 담당 |
|---|---|---|
| 1 | 총괄·방카르 | 목표·우선순위, 팀 지휘, 대표에게 결론 보고 |
| 2 | 리서치·방카르2 | 시장·경쟁·가격·수요 조사 |
| 3 | 마케팅·방카르3 | 채널·문구·가격·프로모션 |
| 4 | 기획·GPT | 범위·일정·산출물·성공 기준 |
| 5 | 개발·클로드 | 구현·동작 확인·걸리는 점 |
| 6 | 검증·제미나이 | 숫자·표현·위험 점검 |

회의 순서: **총괄 → 리서치 → 기획 → 개발 → 마케팅 → 검증**

## 쓰는 법

- 그냥 지시 → 전체 회의
- `@기획` 처럼 한 명만 멘션 → 그 직원만 답변
- `@현황보고` → 각자 완료/진행 중/다음 할 일 보고
- `@전체회의` → 6명 릴레이 회의
- `■ 회의 중지` → 진행 중인 회의 중단

## 설정 (🔑)

1. **GitHub PAT** — `repo` 권한이 있는 classic 토큰. 저장소 `bjyoutube/ai-meeting-room`,
   파일 `office-messages.json`. 10초 자동 확인.
2. **Gemini 키** 또는 **OpenRouter 키** — 무료 발급. 포지션별로 어느 쪽이 답할지 지정 가능.
3. 키가 하나도 없으면 데모 모드로 동작합니다.

## 파일

- `index.html` — 앱 전체(UI + 엔진)
- `office-messages.json` — 공용 대화 파일(앱이 자동으로 읽고 씀)
- `.nojekyll` — GitHub Pages가 파일을 그대로 서빙하도록
