⚙️ API 키 관리

키를 넣은 직원은 실제 AI로, 넣지 않은 직원은 데모 모드로 답합니다. 키는 이 브라우저(localStorage)에만 저장되고, 답변을 만들 때 해당 제공사(Google·Groq·OpenRouter)로만 전송됩니다. 따로 만든 서버는 없습니다.

무료 등급은 분당·일일 호출 한도가 있습니다. 한도를 넘으면 잠시 뒤 다시 시도하거나 데모 모드로 확인하세요. 회사·학교 공용 PC에서는 키를 저장하지 마세요.

❓ 사용 안내

처음 쓰신다면 이 네 가지만 기억하면 됩니다.

1. 그냥 말하기
“몽골 중고차 수출 아이디어 검증해줘”처럼 평소 말투로 적으면 기본 담당자(기획자)가 답합니다.

2. @로 지목하기
@전체를 붙이면 네 명이 차례로, @리서처처럼 한 명만 붙이면 그 직원만 답합니다. 아래 칩을 눌러도 입력창에 들어가요.

3. 퀵 버튼
회의 정리(지금까지 요약) · 할 일 뽑기(실행 목록) · 초안 쓰기(마케팅 문구)를 한 번에 시킬 수 있습니다.

4. 진짜 AI로 쓰기
⚙️에서 무료 API 키를 넣으면 실제 답변이 옵니다. 답변마다 오른쪽 위 라벨로 실제/데모를 구분할 수 있어요.
